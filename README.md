## Portfolio Features

- Responsive neo-brutalist portfolio layout
- Featured PanindaHub project case study
- Custom responsive commerce dashboard preview
- Project technology, feature, role, audience, and deployment details
- Personal profile photo in the About Me section
- Hero introduction with the developer name and role
- Navbar resume button for quick access to a downloadable résumé

## Adding Your Resume

Add your résumé PDF as `public/resume.pdf`. The Resume button in the navbar
will automatically open that file in a new browser tab.
